## Direction and implemented behavior

| Before | After | Reason |
|---|---|---|
| Six equal station cards fill the graph | Compact role anchors plus actual operation nodes | Makes the work the subject of the canvas |
| One card-grid map | Flow and Network arrangements of the same typed scene | Flow supports comprehension; Network supports spatial exploration |
| Broad stage selection only | Select operations and reported-call satellites; retain existing evidence inspector | Connects visible work to its recorded source |
| Diagram cannot be explored | Search displayed nodes, bounded pan/zoom, named Fit/reset, roving keyboard navigation | Makes density inspectable without requiring precise dragging |
| Membership resembles causality | Arrowless membership/activity, arrows only for recorded stage transitions; visible legend | Prevents unsupported dependency claims |
| Hovering text moves a centered point | Fixed-size anchor and separately positioned label | Keeps the visible point aligned to its SVG connection |
| Insertion order defines recent records | Timestamp sort plus deterministic ID tie-breaker | Mixed run/evidence storage order cannot hide newer work |
| Caption covers a narrow operation | Caption outside the plot | Preserves node legibility at 390px |

Default Flow shows up to three recent operations per role. Network retains the latest100 operations and200 reported calls; actual omission counts are explicit. Both receive the historical projection, so future operations, calls and outcomes are absent during replay. Tool ticks contain only kind/time: they are labeled reported read/edit/search/command calls, without invented file names or causal edges. Search covers the displayed graph only, with20 readable results at a time. Recorded calls do not establish success. Existing Timeline, Records, human controls, revision-bound evidence and engine refusal policy remain.

The layout is deterministic and static, with no force simulation, perpetual animation or new dependency. Native buttons, one node tab stop, arrow-key focus, Enter activation, named search results, zoom/fit and existing narrow inspector reveal/return preserve alternative access routes. Long labels open separately from their point and flip left near the right edge. No full WCAG/screen-reader or maximum-density readability certification is claimed.
