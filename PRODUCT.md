# Hydra

Hydra is a local desktop product for supervised AI engineering with the user's own Claude Code and Codex CLI accounts. Questions use a conversation; changes use isolated Git worktrees and engine-owned planning, editing, review, checks and human delivery decisions. Agents take turns within one task. Separate tasks may overlap.

Mission Control starts with a compact project-aware objective composer, account readiness and bounded mission/decision lists. A change opens the orchestration canvas: actual role participants, recorded stage relationships, repairs, engine checks and a human decision. Select an operation to inspect evidence; replay recorded timestamps without invented intermediate activity. Current summaries are never substituted for unavailable historical artifacts. The mission dossier retains plans, current base-to-head diff, exact checks, logs and acceptance receipts. The engine blocks unresolved verification/review across all clients; applying by exception is unsupported.

Supported audience: supervised developer preview on trusted repositories. Project code runs with user permissions. No hostile-repository security promise, complete cost accounting, hard billing cap, automatic installer rollback, secure-erasure promise, public relay or trusted HTTPS phone client. Alpha.5 qualified specific CI platforms/installers; alpha.6 has its own local Windows validation and does not inherit a claim that its changed UI was tested on those other platforms. Production distribution/signing remains incomplete. Local data remains local to Hydra; selected context goes to selected providers.

See docs/v2/PRODUCT_MILESTONE.md for coverage and limitations; docs/v2/AGENSI_FULL_PRODUCT.md for the separate full-app distribution and companion proposal. No sale, publication, license change or main merge is approved by these documents.
