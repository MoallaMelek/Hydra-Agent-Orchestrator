# Hydra

Hydra is a local desktop product for supervised AI engineering with the user's own Claude Code and Codex CLI accounts. Questions use a conversation; changes use isolated Git worktrees and engine-owned planning, editing, review, checks and human delivery decisions. Agents take turns within one task. Separate tasks may overlap.

The Workroom starts with conversation and a bounded decision inbox. Its Proofline links recorded plans, revisions, reviews, checks and delivery decisions to their actual inspector. It never simulates thinking or collaboration. A mission receipt is the primary change artifact. Progressive disclosure keeps operations, replay, technical provider capabilities and check configuration available without making them the starting point. The engine blocks unresolved verification/review across all clients; applying by exception is unsupported.

Supported audience: supervised developer preview on trusted repositories. Project code runs with user permissions. No hostile-repository security promise, complete cost accounting, automatic installer rollback, secure-erasure promise, public relay or trusted HTTPS phone client. Production distribution/signing and cross-platform qualification are incomplete. Local data remains local to Hydra; selected context goes to selected providers.

See docs/v2/PRODUCT_MILESTONE.md for coverage and limitations; docs/v2/AGENSI_FULL_PRODUCT.md for the separate full-app distribution and companion proposal. No sale, publication, license change or main merge is approved by these documents.
